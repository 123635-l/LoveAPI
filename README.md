# LoveAPI

`LoveAPI` is a single-file, offline-friendly static web app for a playful "relationship parameter self-test".

## Contents

- `loveapi_v1_final_standalone.html`: the main standalone app
- `loveapi_v1_poster.png`: poster/cover image
- `loveapi_v1_package.zip`: packaged artifact, kept out of version control by default

## How to use

1. Open `loveapi_v1_final_standalone.html` in a browser.
2. Fill in the form sections.
3. Read the generated summary and share it if you want.

## GitHub Pages

- The repository includes `index.html` as a landing page that redirects to `loveapi_v1_final_standalone.html`.
- When you enable GitHub Pages, point it at the `main` branch and the repository root.
- After GitHub finishes publishing, the site root will open the HTML automatically.
